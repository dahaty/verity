От подключения
до проверенного действия.

Verity встаёт между всеми ИИ-агентами компании и её системами. Агенты подключаются в одну точку, общаются через неё, а агент-контролёр проверяет каждое действие до выполнения.

ПОДКЛЮЧЕНИЕ

Три шага.
Без разработки.

Не нужно встраивать проверки в код каждого агента. Системы, агенты и правила подключаются к Verity один раз.

01

Подключите системы

Войдите в 1С, Битрикс24, amoCRM, МойСклад или любой из 1000+ сервисов. Ключи хранятся в Verity в зашифрованном виде — не в коде агентов.

Минуты
02

Подключите агентов

Каждый агент получает один адрес и свой ключ. Подходит любой агент с поддержкой MCP или HTTP: YandexGPT, GigaChat, Claude, собственный.

Один адрес
03

Задайте правила

Роли и права агентов, лимиты по суммам и количеству, что сверять с данными. Готовые шаблоны для торговли, склада и учёта.

Шаблоны

Агенту достаточно одного адреса

Для агентов с поддержкой MCP это одна запись в настройках. Через этот адрес агент видит все разрешённые ему системы и других агентов — и ничего сверх своих прав.

  • Отдельный ключ для каждого агента
  • Отзыв доступа одной кнопкой
  • MCP для инструментов, A2A — для общения агентов
agent-config.json{
  "mcpServers": {
    "verity": {
      "url": "https://gateway.verity/mcp",
      "headers": { "Authorization": "Bearer agent_sklad_…" }
    }
  }
}

Адрес и ключ в примере условные.

ПУТЬ ОДНОГО ДЕЙСТВИЯ

Семь шагов
за доли секунды.

Каждый запрос агента проходит один и тот же путь. Если любая проверка не пройдена, действие не выполняется, а агент получает причину и верные данные.

  1. АгентОтправляет намерение

    Агент склада хочет поставить резерв 10 шт. Ergo Pro.

  2. ПраваМожно ли этому агенту

    Роль «склад»: резервы разрешены, удаление — нет.

  3. ДанныеСверка с источником

    МойСклад: в наличии 24 шт. — резерв возможен.

  4. ПравилаЛимиты и условия

    Лимит агента — до 100 шт. за операцию.

  5. БезопасностьДанные и инструкции

    Персональные данные замаскированы, вредоносных инструкций нет.

  6. РешениеКонтролёр решает сам

    Разрешено автоматически. Ошибка — вернуть на исправление. Крайний случай — человеку.

  7. ИсторияВсё записано

    Кто, что, по какому правилу и с каким результатом.

БЕЗОПАСНОСТЬ И ДАННЫЕ

Всё идёт через Verity.
Поэтому защита — основа.

Единая точка подключения должна быть защищена лучше, чем каждая система по отдельности. Вот принципы, на которых строится сервис.

Шифрование

Ключи от систем и данные клиентов шифруются при хранении и передаче.

Маскирование ПДн

Персональные данные скрываются до передачи во внешние модели.

Изоляция клиентов

Данные каждой компании хранятся и обрабатываются отдельно.

Серверы в РФ

Хранение и обработка — на территории России по 152-ФЗ.

Не обучаем модели

Ваши данные не используются для обучения каких-либо моделей.

Полный журнал

Каждое действие и решение доступны для аудита и выгрузки.

Подробности — в политике обработки данных и соглашении об обработке данных клиентов.

РЕЖИМЫ

До выполнения —
или для наблюдения.

Основной режим останавливает ошибки до того, как они случились. Режим наблюдения помогает начать без риска и увидеть, что делают агенты сейчас.

ОСНОВНОЙ

Контроль до выполнения

Действие выполняется только после проверки. Ошибка возвращается агенту на исправление, клиент её не видит.

  • Защищает деньги, склад и клиентов
  • Решения — автоматически
  • Человек — только в крайнем случае
ДЛЯ СТАРТА

Наблюдение

Verity видит действия агентов и оценивает их, но не останавливает. Подходит, чтобы за неделю получить табель надёжности и настроить правила.

  • Нулевой риск для текущих процессов
  • Табель надёжности каждого агента
  • Переход в основной режим одной кнопкой
ВОПРОСЫ

Частые
вопросы.

Нужно ли переделывать агентов?

Нет. Агент меняет адрес, по которому обращается к системам, на адрес Verity. Логика и модель агента остаются вашими.

С какими моделями и агентами работает Verity?

С любыми: YandexGPT, GigaChat, Claude, открытые модели и собственные агенты. Правила и проверки одинаковы для всех — поэтому оценка независимая.

Насколько замедляются агенты?

Проверка прав и лимитов занимает миллисекунды, сверка с системой — доли секунды. Проверка свободного текста языковой моделью — около секунды, её включают только там, где это нужно.

Что если Verity недоступен?

Поведение задаёте вы: остановить действия агентов или пропускать только чтение данных. Молча пропустить непроверенное действие шлюз не может.

Когда подключается человек?

Только в крайнем случае: источник данных не отвечает, данные в системах противоречат друг другу или действие выходит за все лимиты. Остальное контролёр решает сам.

Где хранятся данные?

На серверах в России. Данные клиентов обрабатываются по поручению в рамках соглашения об обработке данных и не используются ни для чего другого.

Сколько стоит?

Первые 2 000 проверок в месяц — бесплатно. Дальше 0,7–1 ₽ за проверку, чтение данных — от 0,15 ₽. Для больших объёмов — пакеты и индивидуальные условия.
